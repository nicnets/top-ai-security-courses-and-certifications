## Why This List Exists

AI security education is still fragmented.

A search for AI security courses often produces a mixture of general AI courses, traditional cybersecurity courses, AI governance programs and prompt engineering courses. These are not the same as learning how to secure AI systems.

This repository brings together dedicated AI security learning resources in one place and separates them into:

* **Paid professional training and certifications**
* **Free courses, learning paths and hands-on training**

The goal is simple:

> **Help professionals find credible places to learn AI security without having to search through dozens of unrelated AI and cybersecurity courses.**
